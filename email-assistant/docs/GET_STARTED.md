# Getting started

Two independent halves. Do them in either order.

- **[GOOGLE_CLOUD.md](GOOGLE_CLOUD.md)** — the Gmail API side: enable the API,
  set the scopes, create an OAuth client. Ten minutes in a browser, and nothing
  needs to be installed to do it.

- **[INSTALL_MAC.md](INSTALL_MAC.md)** — the application side: one command to
  install it on a Mac, then connect your mailbox and Claude.

They meet at one point: the Client ID and secret from the first go into `.env`
in the second.
